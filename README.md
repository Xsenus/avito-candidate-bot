# Avito bot

Этот проект реализует базового бота для Авито, который:

- работает без webhook, опрашивая новые чаты Авито;
- отправляет первое сообщение при отклике;
- ведёт короткий сценарий: выбор дня, ФИО, телефон;
- отправляет данные в форму Яндекс Форм.

## Настройка

1. Скопируйте [.env.example](.env.example) в `.env`.
2. Заполните значения:
   - `AVITO_CLIENT_ID`
   - `AVITO_CLIENT_SECRET`
   - `AVITO_USER_ID`
   - `YANDEX_FORM_URL`
3. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Запустите бот без вебхука прямо с компьютера:
   ```bash
   python poller.py
   ```
   Или одним кликом:
   ```powershell
   .\start.ps1
   ```

## Важные замечания

- Для отправки сообщений Авито использует Messenger API и требует действующие ключи доступа.
- В документации Авито на момент проверки поддерживаются текстовые сообщения, поэтому кнопки реализованы как текстовые варианты ответа.
- Для работы с конкретной Яндекс Формой может потребоваться адаптация полей под её реальную структуру.
